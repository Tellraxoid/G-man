# S.T.E.M. Training 1.2.2 Beta

The first installable beta of the complete gym diary.

## Highlights

- Active workout tracking with exercises, working and warm-up sets, RIR, notes, duration, volume, and automatic rest timer.
- Editable programs with exercise order and set/rep targets.
- Calendar history with completed-workout editing.
- Personal records, estimated 1RM charts, weekly goals, streaks, muscle volume, and plate calculator.
- Custom and favourite exercises.
- White exercise illustrations with highlighted working muscle groups.
- Faster set entry: the previous set's weight, reps, RIR, and warm-up state are prefilled.
- Correct movement-specific illustrations across the exercise catalog, including chest flyes, cable work, leg machines, lateral raises, and plank.
- Portable JSON backup and restore.
- New S.T.E.M. visual identity, onboarding, launcher icon, and splash screen.

## Installation

Download the APK attached to this release, open it on Android, and allow installation from the browser or file manager when prompted.

This beta uses a development signing key and is intended for direct testing. A Play Store build will use a separate protected production key.
