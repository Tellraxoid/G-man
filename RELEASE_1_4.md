# S.T.E.M. Training 1.4 Beta

- Non-modal rest timer above bottom navigation; +30 seconds and skip.
- Rest notification with sound/vibration preferences and Android notification settings shortcut.
- Background alarm fallback. Android battery saving can delay background delivery; force-stop/reboot is not supported.
- Weight/repetition +/− controls; configurable weight step.
- Optional Easy / Normal / Hard assessment on working sets, stored independently from RIR.
- Pair adjacent exercises as a superset in an active workout. Rest starts after A2.
- Local post-workout summary and conservative, explainable suggestions. This is rule-based, not a connected AI model.
- Superset and effort fields are included in JSON backup; Room migration preserves existing data.

External AI, health/food data integrations and proposed program rewriting are not yet enabled. No personal health data is transmitted.
